## 🎶 NeonPlaylists

A modern Flask-based web application to build, manage, and explore personal music playlists - featuring neon-themed UI, user authentication, and automatic track lookup via the iTunes API.

---

## ✨ Features
- 🔐 User registration & secure login
- ➕ Create and manage personal playlists
- 🎧 Add songs with title, artist, genre & artwork
- 🔍 Automatic song lookup using the iTunes REST API
- 🖥 Neon-styled responsive interface
- 🎵 Optional audio preview where available

---

## 🛠 Tech Stack

| Technology | Purpose |
|-----------|----------|
| **Python** | Core backend logic |
| **Flask** | Routing, user authentication & server side |
| **Flask-SQLAlchemy** | ORM for database models |
| **SQLite** | Lightweight storage for users & playlists |
| **Requests** | REST API communication with iTunes |
| **HTML / CSS** | UI and neon-themed styling |

---

## 📦 Installation & Setup

```bash
# Clone the repository
git clone https://github.com/ilyassuelen/Music-Playlist-App.git
cd Music-Playlist-App

# Install dependencies
pip install -r requirements.txt

# Start development server
python app.py
```

App runs on: http://localhost:5000
